# Construct AI QR Code Generator with Python

## Project Description

This project is a Python-based QR Code Generator developed for Hands-On Assignment 2 in the Advanced Artificial Intelligence course.

The application allows the user to enter a URL and generates a QR code containing the provided URL. The generated QR code is saved as a PNG image file.

## Technologies Used

- Python 3.10
- Visual Studio Code
- GitHub
- qrcode Python library
- Pillow

## Requirements

Before running the application, Python and the required Python libraries must be installed.

Install the required libraries using:

pip install qrcode

How the Application Works

1. The application prompts the user to enter a URL.
2. The URL is added to a QR code.
3. The QR code is generated using the qrcode Python library.
4. The QR code is rendered as a black-and-white image.
5. The generated QR code is saved as a PNG file.
6. A confirmation message is displayed after the QR code is successfully created.
